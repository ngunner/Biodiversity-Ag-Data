# Bridging Gaps: An Agricultural Perspective on Citizen Science Data in New York State

In this study we investigate the following questions:

* Is there a disparity between citizen science data collected on agricultural lands vs non-agricultural lands?
* Are there relationships between socioeconomic variables and observational coverage of agricultural lands?
* Is there a relationship between agricultural land-use and biodiversity that can be gleaned from GBIF data?
* What level of coverage would be sufficiently useful for the agricultural community in an early pest detection scenario?
